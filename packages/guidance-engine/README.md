# Guidance engine | Motore guida

## Interface | Interfaccia

Prepare a report packet from an analysis result and resolved policy context. The packet contains observed facts, evidence checklist, official route, step-by-step instructions, editable bilingual draft and limitations.

Preparare un pacchetto di segnalazione da un risultato di analisi e un contesto policy risolto. Il pacchetto contiene fatti osservati, checklist evidenze, percorso ufficiale, istruzioni passo passo, bozza bilingue modificabile e limiti.

This module never submits a report. It must preserve the distinction between platform rules, alleged illegal content, post-purchase remedies, intellectual-property reports and immediate safety emergencies.

Questo modulo non invia mai una segnalazione. Deve conservare la distinzione tra regole piattaforma, presunto contenuto illegale, rimedi post-acquisto, segnalazioni di proprieta intellettuale ed emergenze di sicurezza immediate.

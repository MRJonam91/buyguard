# Evaluation | Valutazione

## Interface | Interfaccia

Evaluate a versioned analyzer build against a locked dataset and produce precision, recall, false-positive rate, calibration, confusion matrices, sample sizes and confidence intervals by platform, language and concern.

Valutare una build versionata dell'analyzer su un dataset bloccato e produrre precision, recall, tasso di falsi positivi, calibrazione, matrici di confusione, numerosita e intervalli di confidenza per piattaforma, lingua e problema.

The evaluation module owns benchmark methodology and regression comparison. Runtime confidence must not be marketed as quality until this module demonstrates calibration.

Il modulo di valutazione possiede metodologia benchmark e confronto regressioni. La confidenza runtime non deve essere presentata come qualita finche questo modulo non dimostra la calibrazione.

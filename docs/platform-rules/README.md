# Platform rules | Regole per piattaforma

Platform adapters must document supported page shapes, permissions, visible fields, known limitations, terms/policy assumptions and fixture sources. An adapter must not depend on private APIs, bypass access controls or automate transactions.

Gli adapter di piattaforma devono documentare forme pagina supportate, permessi, campi visibili, limitazioni note, assunzioni su termini/policy e fonti delle fixture. Un adapter non deve dipendere da API private, aggirare controlli di accesso o automatizzare transazioni.

The first planned adapter is Vinted. This directory intentionally contains no selectors until the adapter work begins and its permitted interaction model is checked.

Il primo adapter pianificato e Vinted. Questa cartella non contiene intenzionalmente selector fino all'inizio del lavoro sull'adapter e alla verifica del suo modello di interazione consentito.

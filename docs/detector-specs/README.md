# Detector specifications | Specifiche detector

Each detector specification must define its stable identifier, input signals, rule dependencies, evidence shape, severity policy, known false positives and a positive/negative/borderline fixture set. No detector may make a legal conclusion or call a seller fraudulent.

Ogni specifica detector deve definire identificatore stabile, segnali in input, dipendenze da regole, forma delle evidenze, politica severity, falsi positivi noti e una serie di fixture positiva/negativa/borderline. Nessun detector puo trarre una conclusione legale o definire un venditore truffatore.

Priority M3 detectors: `PHOTO_ONLY`, `SUBSTITUTE_ITEM`, `PRICE_BAIT`, `UNOFFICIAL_AUCTION`, `EXTERNAL_PAYMENT`, `OBJECT_MISMATCH`, `DISCLOSURE_BURIED`.

I detector prioritari M3 sono: `PHOTO_ONLY`, `SUBSTITUTE_ITEM`, `PRICE_BAIT`, `UNOFFICIAL_AUCTION`, `EXTERNAL_PAYMENT`, `OBJECT_MISMATCH`, `DISCLOSURE_BURIED`.

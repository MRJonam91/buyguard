**Reviewed / Revisionata:** 2026-09-20  
**Scope / Ambito:** listing or content concerns in Italy; separate from returns and buyer-protection cases / problemi di inserzione o contenuto in Italia; separati da resi e tutela acquisti

## Steps | Passi

1. On the content page select the question-mark icon; on mobile select the three dots / Nella pagina del contenuto selezionare il punto interrogativo; su mobile i tre puntini.
2. Under **Report content / Segnala contenuto**, select **Submit report / Invia la segnalazione**.
3. Select the correct official content type / Selezionare il tipo ufficiale corretto.
4. Add factual details and only relevant documents / Aggiungere dettagli fattuali e solo documenti pertinenti.
5. Review the good-faith statement and submit personally / Rivedere la dichiarazione di buona fede e inviare personalmente.

For one prohibited or restricted listing, use **Report listing / Report item** where shown. Not-received, damaged or not-as-described purchases use return, refund or buyer-protection flows. Rights holders use VeRO for intellectual-property claims.

Per una singola inserzione vietata o limitata usare **Segnala l'inserzione / Segnala l'oggetto** quando presente. Acquisti non ricevuti, danneggiati o non conformi usano i flussi reso, rimborso o tutela acquisti. I titolari dei diritti usano VeRO per reclami di proprieta intellettuale.

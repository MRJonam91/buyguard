# Web analyzer | Analizzatore web

## Role | Ruolo

The web surface will analyze text, saved HTML, screenshots and structured listing data explicitly supplied by the user. It will display findings, compare deterministic and optional AI review, and let the user inspect or edit a report packet.

La superficie web analizzera testo, HTML salvato, screenshot e dati strutturati dell'annuncio forniti esplicitamente dall'utente. Mostrera finding, confronto tra analisi deterministica e revisione AI opzionale e consentira di ispezionare o modificare un pacchetto di segnalazione.

## Constraint | Vincolo

Arbitrary URL fetching is not part of the initial web surface. A later fetch service would need explicit platform authorization, SSRF defenses, content-size limits, redirect controls, privacy disclosure, retention policy and abuse prevention.

Il fetch di URL arbitrari non fa parte della superficie web iniziale. Un futuro servizio di fetch richiederebbe autorizzazione esplicita della piattaforma, difese SSRF, limiti di dimensione, controllo redirect, informativa privacy, politica di conservazione e prevenzione abusi.

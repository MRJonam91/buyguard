# Desktop application | Applicazione desktop

## Role | Ruolo

The desktop application is the strongest local-first surface for saved pages, screenshots, local OCR, report archives and optional local AI. It consumes the same analysis, policy and guidance interfaces as the browser extension.

L'applicazione desktop e la superficie local-first piu completa per pagine salvate, screenshot, OCR locale, archivio report e AI locale opzionale. Usa le stesse interfacce di analisi, policy e guida dell'estensione browser.

## Constraint | Vincolo

No credential capture, continuous screen recording, hidden background scanning or cloud dependency for the base analysis. Operating-system credential storage is required for any persistent provider secret.

Nessuna cattura credenziali, registrazione continua dello schermo, scansione nascosta in background o dipendenza cloud per l'analisi base. Lo storage credenziali del sistema operativo e obbligatorio per ogni segreto provider persistente.
